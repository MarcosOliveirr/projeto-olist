#  Análise de Satisfação de Clientes — Olist

## Contexto de Negócio
O time comercial da Olist identificou queda na satisfação dos clientes e solicitou uma análise para entender os principais fatores que impactam a experiência de compra.

##  Objetivo
Identificar os principais drivers de insatisfação dos clientes com base em dados reais de pedidos, entregas e avaliações.

## 🔍 Principais Insights
- Atraso na entrega reduz a nota média de **4.29 para 2.27**
- Qualquer atraso, mesmo de 1 dia, já impacta drasticamente a satisfação
- **AL e MA** são os estados com maior % de atraso (+17%)
- **RJ** é prioridade por combinar alto volume com taxa de atraso elevada
- Categorias de móveis e construção concentram as piores avaliações

## Ferramentas Utilizadas
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

[Brazilian E-Commerce — Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
